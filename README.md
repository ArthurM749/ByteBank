

# ByteBank

Projeto da disciplina de Java (Ciência da Computação, Univértix), desenvolvido durante as aulas para praticar interface gráfica e manipulação de dados em Java. Simula um sistema bancário simples.

## O que o projeto pratica

- Criação de telas, botões e formulários em Java
- Manipulação e registro de dados (`historico.txt`)
- Organização de código em pacotes (`com.bytebank`)
- Build com Maven

- Java 17

## Como rodar

Pré-requisitos: JDK 17 e Maven.

```bash
git clone https://github.com/ArthurM749/ByteBank.git
cd ByteBank
mvn compile
```

Execute a classe principal `[com.bytebank.NomeDaClasseMain]` pela sua IDE (por exemplo, IntelliJ IDEA).
